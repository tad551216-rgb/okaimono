# おかいもの帖 v1.6

つくる手帖／放課後デイ応援帖の一冊。
子どもから預かったお金で、おやつ・昼食を買いに行く仕事のための帖です。

- 通信するしくみが入っていません。
- データは端末の localStorage のみ（`tsukuru.okaimono.v1`）。
- テーマ色 #2c5077。支援きろく帖・おむかえルート帖と同じ意匠です。

---

## 画面

| タブ | 中身 |
|---|---|
| 👛 おさいふ | 子ども・みんなのおさいふ・職員の立替。入金／出金／明細 |
| ✍️ リクエスト | ほしいものを聞いて、予定額で仮押さえ |
| 🛒 おかいもの | お店で絞り込んだ買い物リスト。レシートで消し込み |
| 📤 出力 | 月次の預り金報告、QR受け渡し、文字での受け渡し、バックアップ |
| ⚙️ 設定 | こども・お店・商品・職員・名寄せ辞書、事業所、合言葉、サンプル |

---

## 1. はじめの用意（設定）

「設定」で、こども → お店 → ていばん商品 → 職員 の順に登録します。
ニックネームだけで動きます。支援きろく帖と受け渡しをするなら、同じニックネームにそろえてください。

**職員は二人以上**登録してください。預り金の出納には確認者が要ります。

まず試すなら、設定のいちばん下「🧪 サンプルデータを入れて試す」から。
架空のこども4名・お店2件・商品6品・職員2名と、預り金の記録、かりおさえ中のリクエスト4件が入ります。

**同梱の `sample-barcodes.pdf` を印刷すれば（または `sample-barcodes.html` を画面に出したまま読ませれば）、
お店に行かなくてもバーコード消し込みを試せます。**サンプルの商品6品に対応した
架空のJANコードが並んでいます。職員の方へのご説明のときにどうぞ。

---

## 2. お金をあずかる（おさいふ）

入金・出金のたびに **確認した職員（もう一人）** をえらべます。
扱った職員とは別の職員が確認した記録が残ります。

各おさいふには三つの数字が出ます。

| 表示 | 意味 |
|---|---|
| ざんだか | 実際に手元にあるお金 |
| かりおさえ | リクエスト済みでまだ買っていない予定額 |
| つかえる | ざんだか − かりおさえ。マイナスなら赤字表示 |

「みんなのおさいふ」は事業所共通のおやつ代。
「職員の立替」は自腹で払った未精算額で、返したら「立替をせいさん」。

---

## 3. ほしいものを聞く（リクエスト）

「だれのお金で買う」「どのお店で」「商品」「予定単価」「個数」を入れて追加。
追加した時点で、そのおさいふに **予定額で仮押さえ** がかかります。
使えるお金を超える場合は確認が出ますが、追加自体は止めません。

商品はマスタから選べますが、その場で直接入力もできます。

---

## 4. 買いに行く（おかいもの）

- 上のチップでお店を絞り込みます。件数つき。
- **かごに入れるもの** … 同じ商品をまとめて「×3」と表示。買い忘れ防止用。
- その下が一人ずつの明細。買ったらチェック、実額を入れます。
- 品切れなら「買えなかった」。仮押さえが解けます。
- 「レシートで確定」で、買いに行った職員・立替の有無・確認した職員をえらんで確定。

### 📷 バーコードで消し込む

商品にJANコードを登録しておくと、棚の前で読ませるだけでチェックが入ります。
かごを抱えたまま小さな画面のリストを目で追わずに済みます。

- 読み取りの結果は、**映像のすぐ下**に大きく出ます。緑は成功、赤は要確認。
- リングの中に、バーコードがくっきり見える距離（10〜20cm）で数秒止める。
- **缶やペットボトルのような丸い面は苦手です。**平らな面をお選びください。
- とうろくにない番号を読んだときは、その場で「いま持っているのはどの品か」をえらべます。
  えらぶと番号を覚えるので、次からは自動で当たります。買い物をしながら商品が育ちます。
- 登録にない商品は「とうろくにない商品です」と出ます。
- 買うリストにない商品は「買うリストにありません」と出ます。
- 同じものを続けて読んでも二重にはなりません。
- 全部そろうと自動で閉じます。
- 暗いお店では「💡 ライト」を。対応している端末でだけ出ます。

同じ商品を二人以上がたのんでいるときは、その旨が出ますので、人数ぶん読ませてください。

JANコードは「設定」→「ていばん商品」で登録します。「📷 読む」で読み取れば手打ち不要です。
**レシートにJANは印字されません**ので、レシート突合の助けにはなりません。あちらは名寄せ辞書が引き受けます。

### レシートで消し込む

「レシートを読んで消し込む」から、レシートの文字を流し込みます。

- **iPhone・iPad** … 入力欄を長押しして「テキストをスキャン」。カメラを向けるだけ。
- **Android** … キーボードのカメラ（レンズ）で読み取って貼り付け。
- 手で打っても構いません。読み取りは端末の中だけで行われます。

読み取ると、品名と金額を拾って、仮押さえ中のリクエストに突き合わせます。

- 半角カナ・カタカナ・長音・記号のゆれは吸収します（`ｲﾁｺﾞﾎﾟｯｷ-` ＝ `いちごポッキー`）。
- 名前が途中で切られていても当たります。
- 小計・合計・税・お預り・おつり・レジ番号・レジ袋の行は読み飛ばします。
- 値引き行は、直前の品から差し引きます。
- 品名と金額が別の行に分かれる形式（`商品名` / `1 X 218  218`）にも対応します。
- 桁揃えの空白（`小 計` `お 釣 り`）も詰めてから判定します。
- レシート合計と突合合計の差を出します。差が税額とほぼ同じなら、外税のお店だと表示します。

結びつきには「確定／たしか／たぶん／ようかくにん」の目安が付きます。
違っていたらその場でえらび直せます。「むし」にすればレジ袋代などを外せます。

**カタカナと漢字は自動では当たりません**（`ｷﾞｭｳﾆｭｳ` と `牛乳` など）。
一度手で結ぶと名寄せ辞書におぼえるので、次からは自動で当たります。
辞書は「設定」で見られます。同じお店のレシートは同じ略し方をするので、
数週間でほとんど手直しが要らなくなります。

## 5. 端末どうしで渡す（出力）

### ① 同じ場所にいるとき — QRコード

設定の「QRで受け渡すための設定」で、**両方の端末に同じ合言葉**を入れます。
合言葉は口頭か紙で伝えてください。LINEやメールでは送らないこと。

**渡すとき**

1. 出力タブの「📱 おさいふの記録をQRで渡す」または「📱 とうろくをQRで渡す」
2. QRコードが順に切り替わる（一枚には入りきらないため）
3. その画面を、相手の端末に向けたまま持っている
4. 速さは「おそく」「はやく」、止めたいときは「とめる」、手送りは「▶次へ」

**受け取るとき**

1. 出力タブの「📷 カメラで読み取る」
2. カメラを相手の画面に向けたまま持っている
3. 「2 / 5 枚 読み取れました」と増えていく。順番は気にしなくてよい
4. 全部そろうと、自動で取り込まれる

**うまく読めないとき** … QRコードが白い枠いっぱいになるまで近づける。
渡す側の画面の明るさを上げる。これがいちばん効きます。
それでも読めなければ、渡す側の「とめる」で止めてもらってから、一枚ずつ「▶次へ」で送ってもらう。

QRコードを写真に撮られても、中身は合言葉で包まれているため読めません。

### ② 離れた相手に渡す — 文字で貼り付け

合言葉で包んだテキストを書き出して、貼り付けで渡します。
受け取り方は「たし算する」か「入れかえる」を選べます。

### バックアップ

JSONファイルは**そのままでは中身が読めます**。
LINEやメールで送るときは秘密フォルダⅡで暗号化してから、PINは別の方法でお伝えください。
支援きろく帖・入浴きろく帖と同じ運用です。

## 6. 月ごとの預り金報告（出力）

対象の月をえらんで「🖨 預り金報告を印刷する」。
子どもごとに、前月からのくりこし・その月の入出金・月末の残高が並びます。
確認した職員の名前も一緒に出ます。保護者へのご報告にお使いください。

---

## お使いいただく前に、大事なこと

- この帖は預り金の出納を記録する道具です。**このアプリが預り金の管理責任を代替することはありません。**
  管理規程の整備・現金と帳簿の照合・保護者への報告は、事業所の定めに従ってお願いします。
  取り扱いは指定権者によって異なりますので、導入前の確認をおすすめします。
- 預り金の出納の記録は事業所の会計書類です。保存年限は事業所の規程に合わせ、
  月に一度はバックアップを取り、端末以外の場所にも控えを置いてください。
- **先にホーム画面へ追加してからお使いください。**追加せずに使うと、
  しばらく開かない間に記録が消えてしまうことがあります。詳しくは「置き方」の節を。

---

## ⚠ カメラを使うには、置いてから開いてください

**`index.html` をダブルクリックして直接ひらくと、バーコードとQRの読み取りは動きません。**
`file://` で開いたページには、ブラウザがカメラを渡さないためです。押しても何も起きません。

次のどちらかでお使いください。

- **GitHub Pages に置いて `https://` でひらく**（本番の使い方）
- **VS Code の Live Server で `http://localhost` としてひらく**（手元で試すとき）

いまの状態は「設定」→「カメラの状態」で見られます。使えないときは、その理由が出ます。

### 📷 読み取りテスト

うまく読めないときは、「設定」→「カメラの状態」→「📷 読み取りテストをする」。
とうろくを見ずに、読めたものをそのまま出します。

```
ひらき方    https://…
部品        あり
映像        1920×1080
再生        うごいています
経過        12秒
読めた数    3
最後に読めたもの
［EAN_13］
4901234567894
```

**映像が 0×0 のまま** … カメラの映像が届いていません。
**サイズは出るのに読めた数が増えない** … 映像は来ているが解析できていません。
どちらなのかで、原因がはっきり分かれます。

QRの表示・レシートの読み取り・預り金の記録は、`file://` のままでもお使いになれます。

## 置き方（GitHub Pages）

リポジトリの直下に、この6つをそのまま置いてください。

```
index.html                 アプリ本体
sw.js                      オフラインで開くためのもの
manifest.webmanifest       ホーム画面に追加するためのもの
icon-192.png
icon-512.png
icon-maskable-512.png      Androidの丸いアイコン用
sample-barcodes.pdf        お試し用のバーコード表・印刷用A4（置かなくても動きます）
sample-barcodes.html       同じもののHTML版（置かなくても動きます）
```

`index.html` の名前は変えないでください。`sw.js` と `manifest.webmanifest` が
同じ場所にあることが必要です。

### 版を上げるとき

`sw.js` のいちばん上、`const CACHE = "okaimono-1.3.0";` の番号だけを変えてください。
古いキャッシュは自動で捨てられます。番号を変え忘れると、
利用者の端末に古い版が残ったままになります。

新しい版が届くと、画面の下に「新しい版が届いています／読み込み直す」と出ます。

### ホーム画面への追加

- **iPhone・iPad** … Safari で開いて、共有ボタン →「ホーム画面に追加」
- **Android** … Chrome で開いて、メニュー →「アプリをインストール」

**先に追加してからお使いください。**追加せずに使うと、
しばらく開かない間に記録が消えてしまうことがあります。

追加したあとは、電波のない場所でも開きます。カメラを使うため、
はじめの一回だけ「カメラへのアクセス」をお許しください。
