# おかいもの帖 v1.9

つくる手帖／放課後デイ応援帖の一冊。
子どもから預かったお金で、おやつ・昼食を買いに行く仕事のための帖です。

- 通信するしくみが入っていません。
- データは端末の localStorage のみ（`tsukuru.okaimono.v1`）。
- テーマ色 #2c5077。支援きろく帖・おむかえルート帖と同じ意匠です。

---

## 文字の大きさ

「設定」のいちばん上で、**帖ぜんたいの文字の大きさ**を四段から選べます。
初めて開いたときは「大きい」になっています。

| | おかいもの品名 | 金額 | 本文 |
|---|---|---|---|
| ふつう | 19px | 17px | 15px |
| **大きい**（既定） | **24px** | **21px** | **19px** |
| とても大きい | 28px | 26px | 22px |
| 特大 | 34px | 31px | 27px |

押すとすぐに切り替わります。この設定は端末に残り、ほかの端末には伝わりません。
職員の方ごとに端末が違うなら、それぞれで決めていただけます。

下のタブと題字だけは伸びに上限を設けています。字が大きくなりすぎると
五つのタブが横に収まらなくなるためです。

印刷する預り金報告は、この設定の影響を受けません。紙の上での読みやすさは別だからです。

## 1. はじめの用意（設定）

「設定」で、こども → お店 → ていばん商品 → 職員 の順に登録します。
ニックネームだけで動きます。支援きろく帖と受け渡しをするなら、同じニックネームにそろえてください。

**職員は二人以上**登録してください。預り金の出納には確認者が要ります。

まず試すなら、設定のいちばん下「🧪 サンプルデータを入れて試す」から。
架空のこども4名・お店2件・商品6品・職員2名と、預り金の記録、かりおさえ中のリクエスト4件が入ります。
事業所名は「放課後デイサービス　とまと」、職員は「やまだ」「すずき」です。
事業所名をすでに入れておられる場合は、そのまま残ります。

**同梱の `sample-barcodes.pdf` を印刷すれば（または `sample-barcodes.html` を画面に出したまま読ませれば）、
お店に行かなくてもバーコード消し込みを試せます。**サンプルの商品6品に対応した
架空のJANコードが並んでいます。

**`sample-receipts.pdf` は、レシート読み取りのお試し用です。**
1枚目がきれいな印刷、2枚目が感熱紙らしくかすれたもの。どちらも
サンプルデータの商品・金額に合わせてあるので、読み取り→突合→消し込みまで
一続きに試せます。職員の方へのご説明のときにどうぞ。

## 2. お金をあずかる（おさいふ）

入金・出金のたびに **確認した職員（もう一人）** をえらべます。
扱った職員とは別の職員が確認した記録が残ります。

各おさいふには三つの数字が出ます。

| 表示 | 意味 |
|---|---|
| ざんだか | 実際に手元にあるお金 |
| かりおさえ | リクエスト済みでまだ買っていない予定額 |
| つかえる | ざんだか − かりおさえ。マイナスなら赤字表示 |

「みんなのおさいふ」は事業所共通のおやつ代。
「職員の立替」は自腹で払った未精算額で、返したら「立替をせいさん」。

---

## 3. ほしいものを聞く（リクエスト）

「だれのお金で買う」「どのお店で」「商品」「予定単価」「個数」を入れて追加。

**まだえらんでいない欄は、商品名の入力例と同じ薄さで出ます。**
えらぶと濃くなります。「だれのお金で買う」は、えらぶまで追加できません。
選んだつもりがないまま、別の子のお財布から引き落とす事故を防ぐためです。

**追加すると、すべての欄が空に戻ります。**
選び終えた状態が残っていると、次の子のぶんを入れるときに取り違えるためです。
毎回えらび直していただくことになりますが、そのぶん誤りが起きません。
追加した時点で、そのおさいふに **予定額で仮押さえ** がかかります。
使えるお金を超える場合は確認が出ますが、追加自体は止めません。

商品はマスタから選べますが、その場で直接入力もできます。

## 4. 買いに行く（おかいもの）

- 上のチップでお店を絞り込みます。件数つき。
- **かごに入れるもの** … 同じ商品をまとめて「×3」と表示。買い忘れ防止用。
- その下が一人ずつの明細。買ったらチェック、実額を入れます。
- 品切れなら「買えなかった」。仮押さえが解けます。
- 「レシートで確定」で、買いに行った職員・立替の有無・確認した職員をえらんで確定。

### 📷 バーコードで消し込む

商品にJANコードを登録しておくと、棚の前で読ませるだけでチェックが入ります。

**映像の下に、買うものがそのまま並びます。**読むとその行に取り消し線が入り、
薄い緑になって下へ落ちます。何が起きたかを文で読む必要はありません。
残っているものが上に、済んだものが下に。見出しに「のこり ◯件」。

画面は上から **映像 → 知らせ → 操作 → 一覧** の順です。
いま応えていただくことが上、参考の一覧が下になります。

映像は画面の1/4を必ず確保します（下限150px）。一覧に押し出されて狭くなることはありません。
品名が長いときは二行まで折り返します。「ツナマヨおにぎ…」のように切れません。

**問いかけが出ているあいだ、一覧は引っこみます。**「どの品ですか」「買うものに足しますか」
と聞いているときに、下の一覧が答えの選択肢を押し下げないためです。
「とばす」を押すと一覧が戻ります。

読めたときの文字帯は出しません。一覧が同じことを言っているからです。
帯が出るのは、伝えることがあるときだけ——「同じものが あと ◯件」「とうろくにない番号です」など。

読めたときは、**音・振動・画面の閃光**の三つで知らせます。
かごを抱えて画面を見ていなくても分かります。成功は高い音、それ以外は低い二段の音です。
（iPhoneは振動しませんが、音と光は出ます。）

- リングの中でくっきり見える距離（10〜20cm）で、数秒じっと止めてください。
- **缶やペットボトルの曲がった面でも読めます。**縦向きのバーコードも大丈夫です。
  映像を回して読み直すしくみが入っているためで、実機で確認しています。
- 暗いお店では「💡 ライト」を。iPhoneでも出ます。対応していない端末では表示されません。
- **お店の絞り込みは、バーコードには効きません。**手に持っている物が画面の都合で
  見えなくなるのは筋が通らないので、かりおさえ中のもの全部から探します。
- 同じ商品を二人以上がたのんでいるときは、人数ぶん読ませてください。一件ずつ消えます。
- ぜんぶそろうと「✓ ぜんぶ そろいました」と出て、しばらくして自動で閉じます。

**とうろくにない番号や、だれも頼んでいない品を読んだときは、その場で止まります。**
カメラも一度止まり、決めていただくまで次に進みません。

手に持っているものと番号の対応は、その瞬間にしか分かりません。
あとで「4995555555555 はどの品でしたか」と聞かれても、答えようがないためです。

| 読んだもの | 聞かれること |
|---|---|
| とうろくにない番号 | この番号は、どの品ですか（買うリストからえらぶ） |
| だれも頼んでいない品 | だれのお金で買いますか |

えらんで決めると、番号をおぼえて、同時にチェックも入ります。
その品を買わないなら「買わない（読み取りにもどる）」。何も残さず戻ります。

一度おぼえた番号は、次から自動で当たります。買い物をしながら商品が育ちます。

JANコードは「設定」→「ていばん商品」で登録します。「📷 読む」で読み取れば手打ち不要です。
**レシートにJANは印字されません**ので、レシート突合の助けにはなりません。あちらは名寄せ辞書が引き受けます。

## 4-2. すんだもの（おかいもの → すんだもの）

おかいものタブの上に「かりおさえ中／すんだもの」の切り替えがあります。
確定した買いものと「買えなかった」ものが並びます。

見方は三つ。**ぜんぶ（日ごと）／こども別／お店別**。

- **ぜんぶ** … 日ごとにまとまります。その日いくら使ったかが分かります
- **こども別** … その子の履歴が一本にまとまります。保護者からのお問い合わせに
- **お店別** … そのお店でいくら使ったかが分かります

まとめた単位の情報は、行から省きます。こども別なら呼び名のふだを、
お店別なら店名を出しません。同じことが二度出て読みにくくなるためです。

```
2026/8/1   4件  ¥944  買えなかった 1件

  いちごポッキー              ¥168
    たろうくん / おやつ  スーパーやまと／やまと   よていどおり

  からあげ弁当               ¥420
    けんとくん / 昼食  スーパーやまと／やまと   よてい +¥22

  ゼリー                   買えず
    ゆいちゃん / おやつ  ドラッグいずみ
```

一件を押すと、その顛末が開きます。

- たのまれた日／買った日
- お店、よてい額、じつがく、差額
- 買いに行った職員、立替だったかどうか、確認した職員
- おさいふからいくら引き落とされたか

**「買えなかった」ものも消えずに残ります。**品切れで買えなかったとき、
後から「なぜ買ってこなかったのか」をご説明いただけます。
仮おさえは解けているので、おさいふのお金は減っていません。
その画面から「もう一度たのむ」で、かりおさえに戻せます。

## 5. 端末どうしで渡す（出力）

### ① 同じ場所にいるとき — QRコード

設定の「QRで受け渡すための設定」で、**両方の端末に同じ合言葉**を入れます。

**日本語の合言葉を入れるときは、右の「見る」を押してから打ってください。**
伏せ字のままだと、iPhoneが日本語入力を受け付けません。
合言葉は口頭か紙で伝えてください。LINEやメールでは送らないこと。

**渡すとき**

1. 出力タブの「📱 おさいふの記録をQRで渡す」または「📱 とうろくをQRで渡す」
2. QRコードが順に切り替わる（一枚には入りきらないため）
3. その画面を、相手の端末に向けたまま持っている
4. 速さは「おそく」「はやく」、止めたいときは「とめる」、手送りは「▶次へ」

**受け取るとき**

1. 出力タブの「📷 カメラで読み取る」
2. カメラを相手の画面に向けたまま持っている
3. 「2 / 5 枚 読み取れました」と増えていく。順番は気にしなくてよい
4. 全部そろうと、自動で取り込まれる

**うまく読めないとき** … QRコードが白い枠いっぱいになるまで近づける。
渡す側の画面の明るさを上げる。これがいちばん効きます。
それでも読めなければ、渡す側の「とめる」で止めてもらってから、一枚ずつ「▶次へ」で送ってもらう。

QRコードを写真に撮られても、中身は合言葉で包まれているため読めません。

### ② 離れた相手に渡す — 文字で貼り付け

合言葉で包んだテキストを書き出して、貼り付けで渡します。
受け取り方は「たし算する」か「入れかえる」を選べます。

### バックアップ

JSONファイルは**そのままでは中身が読めます**。
LINEやメールで送るときは秘密フォルダⅡで暗号化してから、PINは別の方法でお伝えください。
支援きろく帖・入浴きろく帖と同じ運用です。

## 6. 月ごとの預り金報告（出力）

対象の月をえらんで「🖨 預り金報告を印刷する」。
子どもごとに、前月からのくりこし・その月の入出金・月末の残高が並びます。
品名の下に、確認した職員の名前が小さく入ります。保護者へのご報告にそのままお使いいただけます。
この報告は画面の文字倍率の影響を受けません。紙の上での読みやすさは画面とは別だからです。

## お使いいただく前に、大事なこと

- この帖は預り金の出納を記録する道具です。**このアプリが預り金の管理責任を代替することはありません。**
  管理規程の整備・現金と帳簿の照合・保護者への報告は、事業所の定めに従ってお願いします。
  取り扱いは指定権者によって異なりますので、導入前の確認をおすすめします。
- 預り金の出納の記録は事業所の会計書類です。保存年限は事業所の規程に合わせ、
  月に一度はバックアップを取り、端末以外の場所にも控えを置いてください。
- **先にホーム画面へ追加してからお使いください。**追加せずに使うと、
  しばらく開かない間に記録が消えてしまうことがあります。詳しくは「置き方」の節を。

## ⚠ カメラを使うには、置いてから開いてください

**`index.html` をダブルクリックして直接ひらくと、バーコードとQRの読み取りは動きません。**
`file://` で開いたページには、ブラウザがカメラを渡さないためです。押しても何も起きません。

次のどちらかでお使いください。

- **GitHub Pages に置いて `https://` でひらく**（本番の使い方）
- **VS Code の Live Server で `http://localhost` としてひらく**（手元で試すとき）

いまの状態は「設定」→「カメラの状態」で見られます。使えないときは、その理由が出ます。

### 📷 読み取りテスト

うまく読めないときは、「設定」→「カメラの状態」→「📷 読み取りテストをする」。
とうろくを見ずに、読めたものをそのまま出します。

```
ひらき方    https://…
部品        あり
映像        1920×1080
再生        うごいています
経過        12秒
読めた数    3
最後に読めたもの
［EAN_13］
4901234567894
```

**映像が 0×0 のまま** … カメラの映像が届いていません。
**サイズは出るのに読めた数が増えない** … 映像は来ているが解析できていません。
どちらなのかで、原因がはっきり分かれます。

QRの表示・レシートの読み取り・預り金の記録は、`file://` のままでもお使いになれます。

## 置き方（GitHub Pages）

リポジトリの直下に、この6つをそのまま置いてください。

```
index.html                 アプリ本体
sw.js                      オフラインで開くためのもの
manifest.webmanifest       ホーム画面に追加するためのもの
icon-192.png
icon-512.png
icon-maskable-512.png      Androidの丸いアイコン用
okaimono-guide.pdf         職員向けの案内・QRつきA4（置かなくても動きます）
sample-barcodes.pdf        お試し用のバーコード表・印刷用A4（置かなくても動きます）
sample-receipts.pdf        お試し用のレシート・印刷用A4 2枚（置かなくても動きます）
sample-barcodes.html       同じもののHTML版（置かなくても動きます）
```

`index.html` の名前は変えないでください。`sw.js` と `manifest.webmanifest` が
同じ場所にあることが必要です。

### 版を上げるとき

`sw.js` のいちばん上、`const CACHE = "okaimono-1.3.0";` の番号だけを変えてください。
古いキャッシュは自動で捨てられます。番号を変え忘れると、
利用者の端末に古い版が残ったままになります。

新しい版が届くと、画面の下に「新しい版が届いています／読み込み直す」と出ます。

### ホーム画面への追加

- **iPhone・iPad** … Safari で開いて、共有ボタン →「ホーム画面に追加」
- **Android** … Chrome で開いて、メニュー →「アプリをインストール」

**先に追加してからお使いください。**追加せずに使うと、
しばらく開かない間に記録が消えてしまうことがあります。

追加したあとは、電波のない場所でも開きます。カメラを使うため、
はじめの一回だけ「カメラへのアクセス」をお許しください。

## 同梱しているもの

- qrcode-generator v2.0.4（MIT / Kazuhiko Arase）— QRコードの生成
- sample-barcodes.html のバーコードは EAN-13 で、架空の商品コードです。実在の商品とは関係ありません。
- jsQR v1.4.0（Apache-2.0 / Cognex Corporation）— QRコードの読み取り

どちらもファイルの中に入れてあります。外部から読み込むことはありません。**「📷 レシートを撮る」で、その場で読み取れます。**
カメラが立ち上がり、撮ったレシートの文字がそのまま入ります。
すでに撮ってある写真からは「🖼 写真からえらぶ」。

はじめの一回だけ、読み取りのしくみ（約8MB）を取りに行くので時間がかかります。
**電波のあるところで一度お試しください。**二度目からは端末に残るので、
お店の中で電波が悪くても使えます。

読み取りはすべて端末の中で行われます。写真もどこにも送られません。

感熱紙のレシートは文字が細いので、明るいところで、まっすぐ、
レシート全体が入るように撮ってください。読み取ったあとで手直しできます。
